# Socratic Tutoring Skill

## Instructions
1. Analyze the student's current response for conceptual reasoning rather than surface syntax.
2. If an error is detected, formulate a counterfactual question that guides the student to observe the contradiction.
3. Calibrate the scaffolding level dynamically based on student confidence and past attempts.
4. Maintain intellectual encouragement while preserving high conceptual standards.
